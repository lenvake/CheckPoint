## 📋 Key Features

✅ **TLS/HTTPS Analysis**
- Protocol version detection (TLS 1.2, 1.3)
- Certificate validity & expiration
- HSTS & preload checking

✅ **Compliance Checks**
- Impressum detection
- Datenschutz (Privacy Policy)
- DSB (Data Protection Officer) link

✅ **Server Intelligence**
- IP Geolocation
- CDN Detection
- ISP & ASN lookup

✅ **Security.txt**
- Parsing & validation
- Contact info extraction
- Expiration checking

✅ **ISO Certifications**
- ISO 27001, ISO 9001
- SOC 2 Type II evidence
- Custom search patterns

✅ **BFS Crawling**
- Configurable depth & page limits
- Link extraction & deduplication
- Same-domain validation

✅ **Scoring Engine**
- Weighted multi-criteria scoring (0-100)
- Grade classification (A+ to F)
- Detailed point breakdown

✅ **Rich Frontend**
- Real-time loading indicator
- Interactive modal details
- Export (JSON, CSV)
- Responsive design
