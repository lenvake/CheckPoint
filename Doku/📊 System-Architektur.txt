├───────────────────────────────────────────────────────────────────┤

                        ▼
┌───────────────────────────────────────────────────────────────────┐
│                     Crawler (Orchestration)                       │
├───────────────────────────────────────────────────────────────────┤
│ def crawl(url: str, max_pages: int = 80, max_depth: int = 3) → dict│
├───────────────────────────────────────────────────────────────────┤
│ 1. Normalize URL + Scope (http_utils.norm_url, same_reg_domain)    │
│ 2. TLS Analyse (tls_analyzer.analyze_tls(hostname))                │
│ 3. Fetch root (http_utils.fetch) → headers                         │
│ 4. HSTS Check (tls_analyzer.check_hsts(headers))                   │
│ 5. HTTP→HTTPS Redirect-Chain (http_utils.check_redirect_chain)     │
│ 6. Mixed Content (Startseite) (page_analyzer.detect_mixed_content) │
│ 7. Geo/Server (geo_server.get_server_info)                         │
│ 8. DNS Security (dns_security.analyze_dns_security)                │
│    - DNSSEC / DMARC / SPF / DKIM / MX                              │
│ 9. security.txt (page_analyzer.parse_security_txt)                 │
│    - /.well-known/security.txt und /security.txt                   │
│ 10. Sitemap boost (http_utils.fetch_sitemap_urls, max_urls=50)     │
│ 11. BFS-Crawl (Budget & Tiefe)                                     │
│    - Seed URLs aus SEED_PATHS                                      │
│    - sitemap_urls werden priorisiert                               │
│    - pages_crawled < max_pages                                     │
│    - if depth < max_depth → extract_links() → enqueue              │
│    - allow_playwright nur für compliance-verdächtige URLs          │
│    - Early stop wenn Impressum + Datenschutz + DSB + Zertifikate   │
│ 12. PDF Verarbeitung (optional, bis 5 PDFs)                        │
│    - http_utils.extract_pdf_text + classify_page(pseudo_html)      │
│ 13. Compute Score (scoring.compute_score)                          │
│ 14. Return ScanResult (JSON-serializable dict)                     │
└───────────────────────┬──────────┬──────────┬──────────┬──────────┘

## 🔄 Datenfluss – Scan-Prozess (UPDATED)

1. USER Input (URL)
   │
   └──► 2. FORM VALIDATION
       │
       └──► 3. LOADING OVERLAY (Ring + Steps)
           │
           └──► 4. API CALL (POST /api/scan)
               │
               ├──► Backend: crawl()
               │    │
               │    ├─► TLS: analyze_tls + HSTS + Redirect-Chain
               │    ├─► Mixed Content: Startseite
               │    ├─► DNS Security: DNSSEC / DMARC / SPF / DKIM / MX
               │    ├─► Server & Geo: IP/ASN/CDN/Region (falls vorhanden)
               │    ├─► security.txt: parse & validate (Info)
               │    ├─► Sitemap boost + BFS Crawl (max_pages/max_depth)
               │    ├─► Compliance: Impressum / Datenschutz / DSB
               │    ├─► Zertifikate & Normen: Evidenz + Gewichtung
               │    ├─► Optional: PDF extraction + Re-Check
               │    └─► Score: compute_score() (fix 0–100) + Grade A+…F
               │
               └──► 5. RENDER RESPONSE
                    │
                    ├─► Score Hero (Ring, Grade, Pills)
                    ├─► Cards (TLS, DNS, Compliance, Zertifikate, Server)
                    ├─► Breakdown (points/max/reason je Kriterium)
                    ├─► Modals (Details je Kategorie)
                    └─► Export (JSON, CSV)
