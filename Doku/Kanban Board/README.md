### Wechsel zum Kanban Board für Epics & User Stories

Wir sind zum **Kanban Board** als zentrale Übersicht für User Stories und Epics gewechselt.

---

### Warum wir uns dafür entschieden haben

Der Wechsel bringt mehrere Vorteile im täglichen Arbeiten:

- **Mehr Übersicht**: Epics und zugehörige User Stories sind klarer strukturiert und schneller erfassbar.
- **Besserer Arbeitsfluss**: Aufgaben lassen sich einfacher pflegen, priorisieren und im Team koordinieren.
- **Kommentarfunktion**: Abstimmungen, Rückfragen und Entscheidungen können direkt am jeweiligen Item dokumentiert werden.
- **Transparenz**: Fortschritt und Verantwortlichkeiten sind ohne zusätzliche Listen oder Status Abfragen sichtbar.
  
Besserer Arbeitsfluss: Wir schneiden Anforderungen bewusst in mehrere kleinere User Stories statt in wenige große.
So fällt uns die Umsetzung im Alltag leichter: Aufgaben sind klarer abgegrenzt, schneller erledigt und lassen sich besser parallel bearbeiten.

### Erklärung der Darstellung im Board

Im Kanban Board ist die Darstellung wie folgt aufgebaut:

- **Labels entsprechen den Epics**
  - Jedes Epic wird über ein Label abgebildet.
  - So ist schnell erkennbar, zu welchem übergeordneten Thema eine User Story gehört.

- **„Sub Issues Progress“ zeigt den Fortschritt der Epics**
  - Unter Sub Issues Progress sieht man den Status der zugehörigen User Stories.
  - Da ein Epic aus **mehreren User Stories** besteht, ergibt sich der Epic Fortschritt direkt aus dem Fortschritt dieser Stories.
